How to read this

This is the server's own CPU%, self-reported over ws://.../ws/system. It's informational only — the actual restart decision is made independently by supervisor.js, which samples the server process from the outside via pidusage. Run npm run supervise instead of npm start on the backend to have restarts actually happen.
